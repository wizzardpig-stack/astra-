# ASTRA // SIGNATURE

A local-first astrology and developmental interpretation instrument. ASTRA accepts birth data, computes an astronomically derived chart, and presents the result as an interactive signature rather than a generic horoscope feed.

## Live

https://wizzardpig-stack.github.io/astra-/

## What it demonstrates

- Client-side birth-data workflow and chart visualization
- Multiple interpretation lenses and visual palettes
- Responsive three-panel desktop composition with a dedicated phone layout below 820px
- Dynamic viewport sizing, internal panel scrolling, and narrow-phone composition changes
- Touch gesture handling, keyboard/focus hardening, and reduced-motion support
- Iterative correctness and release engineering on a domain-specific browser application

## Stack

HTML, CSS, vanilla JavaScript and SVG.

## Source of truth

Current public release: **ASTRA v1.0**.

`app.html` is the self-contained application build. The root `index.html` is the stable public loader and launch surface.

## Development approach

Independent product direction, domain framing, interface design, iterative testing, QA, and AI-assisted implementation. ASTRA is built as a self-contained browser application with no required account or backend.

## Status

Public launch build. Temporary cross-project test files have been removed from the repository.
